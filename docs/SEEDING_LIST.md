Generated 2026-10-20 by `scripts/seeding_list.py` from `config/letter_sources.toml` and the database. The
automation asks only for periods ending after 2026-06-30 (W-055); everything older on this list is a
one-off back-collection, a good intern task (the owner, 2026-10-20). Periods the database already holds are
left out; rerun the script after a batch has been loaded to get the remainder.

How to drop a file: put it in `Whale Tracker Inbox\public-websites\<manager-slug>\` (any file name), or in
`shared-by-manager\<manager-slug>\` if the manager sent it. The loader works out the period from the
file; a period in the file name (`Q3 2025`, `2025 annual letter`) helps. Internal use only (W-043): nothing
collected here is quoted or sent outside the firm.

Sources marked (not machine-read) are listed too: worth holding, but not analysed until the publisher
consents (W-035).
